HOW TO MAKE USE OF THE COMPUTER ORGANIZER?


In this form, the following will contain the description on what are the usage as well as the functionalities of the organizer in order to both better make use as well as interact with the website.




1. The Earnings Table


In the home user interface, the summarized earnings table can be seen with the containing the earnings of each individual computers as well as their the overall earnings of all of them located at the bottom. If the user wishes to reroll for another earning count, they can reset the table again, removing the existing datas within.






2. Proceeding to the main organizer Interface


When it comes to proceeding to the actual computer management system, the button located at the header will take the user to the user interface for organizing the instances of the registered comptuers.






3. Creating a new host computer


When navigating to the main organizer interface, various forms can be located at the left side of the webpage as well as the a table containing statuses of the of the registerd comptuers. The user cannot create a same PC that has the same ID.






4. Updating an existing computer


When a computer has been registed, the user may now interact with it, otherwise this will return an error indicating that the inserted computer does not exist. In here, the user needs to input the total hours a computer can be ran as well as the total money that was given for that host computer.






5. Removing/Shutdown a running computer


When an instance of computer is up, it will not automatically turn that computer off but will instead give the owner the oppotunity to give them a grace period for them to either close all necessary/important tabs and files as well as purchase a time extension if need be.







6. Removing an Existing computer


Lastly, the option of removing a computer can be selected at the very bottom for instanes such as updating an ip address or removing a host commputer from the system.
